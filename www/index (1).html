How to use / troubleshooting

Use

  1. Type your name in Workbook once (front page).
  2. Tap + Add Group, name it, then choose level, group language and theme.
  3. Add the students. Switch groups with the tabs at the top — each keeps its own data.
  4. Tap Generate Excel: one file with the front page, every group’s register (L1–L24 + the additional L25) and the back page. Print A4 landscape. Untick a group in Workbook to leave it out.

If something goes wrong

  • No download: tap “Download again” or “Share” under the message.
  • More than 15 students: the register has 15 rows — make a second group.
  • Groups disappeared: browser data was cleared — use Import backup.
  • Names, phones and addresses are written exactly as typed (only leading/trailing spaces are removed).
